# v2.0.0 开发记录

日期：2026-10-08（北京时间）。目标：适配 Cloudflare Workers + D1，在浏览器生成 PDF。

## 完成的改造

- 新增独立 Workers 后端，保留 Flask 本地入口；使用原列表页面生成云端静态资源。
- D1 保存业务、变更历史、账号、会话和登录失败计数；业务删除级联清理历史。
- 业务新增、查看、编辑、状态更新、日期逻辑校验；保留搜索、排序、统计、分页和选择交互。
- 密码派生在浏览器完成，Workers 只做轻量验证；管理员账号通过工具建立，不预置云端密码。
- 管理员可删除/导出；写请求校验同源，输出业务名称等文本时转义 HTML。
- 头像作为小图保存到 D1，避免依赖 R2；所有页面依赖打包到本地静态资源。
- 浏览器生成中文 A4 横向 PDF，保留选中导出/确认全部导出规则，按实际行高分页。
- 版本号和 README 更新为 2.0.0，提供部署和迁移命令。

## 验证结果

- 自动测试3组全部通过：非法日期/金额/状态、登录授权和业务完整流程、登录限流。流程涵盖分页、搜索通配符处理、状态历史、选中/全部导出、HTML转义、级联删除、退出会话失效和普通用户权限。
- 在真实 Wrangler 4.148.0 / workerd 本地环境应用 D1 表结构并导入196条业务、199条有效历史。
- 原库共有203条历史，其中4条引用已删除的业务；导出工具跳过孤立记录，未修改原库。
- Puppeteer 在真实 Workers 本地服务验证登录、50条分页、选择、导出确认、PDF下载和手机布局。
- 选中1条业务 PDF 为1页；全部196条业务 PDF 为22页、约5.3MB。页面脚本错误0，外部资源请求0，手机页面无整体横向溢出。
- `wrangler deploy --dry-run` 通过，22个静态文件，Worker约25KB（压缩约8.6KB）。
- 本地运行器最初因代理下载中断而缺失，直连官方 npm 后安装成功。
- compatibility_date 设为运行器支持的2026-10-06，避免选择尚未支持的日期。
- 修复原列表用户菜单访问不存在元素导致的脚本错误。

## 范围和下一步

- 仍未发布到 Cloudflare，也没有开通付费服务。wrangler.jsonc 的数据库ID仍是占位值。
- 下一步需要有效 Cloudflare 登录，创建D1、填写ID、创建正式管理员、迁移业务并部署，然后验证线上CPU指标和访问。
- 原Flask数据库与D1独立，未设置双向同步；原有账号需要在云端重新建立。
- 浏览器PDF为图片式文档，文字不能搜索或复制；这项变化已在部署指南中说明。
- 大规模数据的CPU、D1额度和手机导出性能尚未进行压力验证，不能承诺超出免费额度仍能运行。
- 本地数据库、数据SQL、测试PDF/截图、node_modules和运行器状态均被gitignore排除。
